# My-name-booteable

## Bootloader
Implementación de un programa bootloader realizado en ensamblador x86, el cual será capaz de ejecutar una aplicación llamada my name. Este bootloader se encargará de cargar y ejecutar la aplicación en el espacio de memoria adecuado, incluyendo un mensaje de bienvenida antes de iniciar la aplicación.

--

## My name

La idea fundamental de este juego es crear una pantalla donde aparecerá el nombre de los dos integrantes en una posición random de pantalla. El programa deberá permitir las letras en todos los movimientos, las cuales son las siguientes:

- Flecha derecha
- Flecha izquierda
- Flecha arriba
- Flecha abajo

Se podrá reiniciar el juego en cualquier instante, así como finalizarlo (utilizando teclas) y deberá esperar una confirmación para poder iniciar a jugar.
